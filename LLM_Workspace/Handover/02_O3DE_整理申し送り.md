# O3DE 整理申し送り

## 1. 概要

ProjectSansa は ecosystem / federation / architecture repository として整理を進める。

そのため、O3DE / engine 固有 implementation は、ProjectSansa の主責務から分離する。

---

## 2. 基本方針

ProjectSansa では、以下を原則として保持しない。

- engine-specific implementation
- runtime implementation
- rendering implementation
- engine build environment
- engine plugin implementation

これらは、必要に応じて以下へ移行または再設計する。

- SansaXR
- 専用 repository

---

## 3. 整理対象

### 実装成果物

```text
src/GameEngine/
```

### engine / O3DE 固有ドキュメント

```text
docs/ja-JP/o3de/
```

---

## 4. SansaXR 側で扱う内容

SansaXR 側では、以下を扱う。

- O3DE runtime integration
- engine runtime
- engine plugin
- engine networking
- OpenXR runtime integration
- runtime-side synchronization
- runtime-side rendering integration

---

## 5. ProjectSansa に残す内容

ProjectSansa には、以下のみを残す。

- ecosystem architecture
- federation
- interoperability
- runtime abstraction concept
- distributed architecture
- compatibility
- repository federation

---

## 6. 整理優先順位

### Phase 1

- src/GameEngine/ 削除
- repository federation 文書化
- SansaXR 申し送り整理

### Phase 2

- docs/ja-JP/o3de/ 分離
- engine 固有 setup 分離
- engine build 手順分離

### Phase 3

- ProjectSansa ecosystem repository 化
- implementation monorepo 状態解消
