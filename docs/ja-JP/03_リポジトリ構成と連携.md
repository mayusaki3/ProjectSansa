# リポジトリ構成と連携

## 1. 概要

Sansa 系列は、単一の巨大リポジトリではなく、責務ごとに分離された複数リポジトリで構成する。

ProjectSansa は、それらの関係・責務境界・共通認識を管理する。

## 2. 主要リポジトリ

| リポジトリ | 主責務 |
|---|---|
| ProjectSansa | 全体構想、共通用語、共通方針、導線 |
| SansaSphere | 認証、権利処理、来歴検証、経済圏、ポータル |
| SansaXR | XR Runtime、OpenXR、Networking、VRSNS 体験 |
| SansaVRM | コンテンツフォーマット、スキーマ、検証 |
| SansaVRM Studio AI | SansaVRM コンテンツ制作環境、AI 支援 |
| SansaCloth | 服・皮膚表現向けシェーダー、レンダリング連携 |
| SansaVRM MuJoCo Adapter | SansaVRM と MuJoCo の変換・連携 |

## 3. 避ける構成

- ProjectSansa に個別実装を集約する。
- 各リポジトリが同じ共通用語を独自定義する。
- フォーマット層が Runtime 実装へ直接依存する。
- ガバナンスや来歴の共通概念を各リポジトリで重複管理する。

## 4. 英語名との対応

日本語文書では `リポジトリ構成と連携` を使用する。英語文書では、必要に応じて `Repository Federation` または `Repository Topology` を使用できる。
