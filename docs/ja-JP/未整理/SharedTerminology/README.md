# SharedTerminology

## 1. 概要

SharedTerminology は、Sansa ecosystem 内で shared semantics を維持するための terminology directory である。

ProjectSansa は shared terminology authority として扱う。

---

## 2. 目的

cross-repository semantic divergence を防ぐ。

特に以下を対象とする。

- governance semantics
- provenance semantics
- assembly semantics
- conversion semantics
- federation semantics

---

## 3. terminology examples

### governance / provenance

- provenance
- provenance chain
- provenance graph
- governance
- restriction
- ownership
- verification
- trust
- policy

### workflow / assembly

- assembly
- modular assembly
- derivation
- conversion
- component
- creator
- assembler
- distributor

### federation / ecosystem

- federation
- federation trust
- distributed verification
- signed audit event
- distributed timestamp

---

## 4. Important policy

各 repository は terminology consumer として扱う。

repository-specific extension のみ repository 側で定義する。

shared concepts 自体は ProjectSansa terminology authority を参照する。
