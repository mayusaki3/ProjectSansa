## 3. 正規 index から除去する対象

以下は、HLDocS index から除去する。

| 対象 | 理由 |
|---|---|
| 再構成中ドキュメント | 作業管理情報 |
| 再構成前ドキュメント | 作業管理情報 |
| TODO 的記述 | index 非対象 |
| 移行途中注記 | note 化対象 |
| 作業状態見出し | index 非対象 |

これらは、専用 note へ分離する。

HLDocS 化後の `docs/ja-JP/目次.md` は、以下の構造を推奨する。

```text

├ マニュアル

├ データ定義
├ テスト仕様
```
