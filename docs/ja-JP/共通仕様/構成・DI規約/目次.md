# 構成・DI規約 目次

本ディレクトリは、Project Sansa 全体に共通する  
**Spring Boot 構成・DI（Dependency Injection）・Profile 運用規約**を定義する。

本規約は以下を目的とする。

- Profile 切替時に **Bean が一意に決定されること**
- 本番／テスト／IT 環境で **意図しない Bean 混在を防止すること**
- テスト失敗時に **ApplicationContext 崩壊を連鎖させないこと**
- Mail / Store / Clock / RateLimiter 等、**将来の拡張に耐える共通ルール**を確立すること
