# sansa-testkit 概要と目的

## 1. 位置づけ

`sansa-testkit` は、Project Sansa における **テスト基盤（Test Infrastructure）** の中核を担う共通モジュールである。

主な目的は以下のとおり。

- テスト番号・出力フォーマットを **プロジェクト横断で統一**する
- テストコード・テスト仕様・実行ログを **1:1 で追跡可能**にする
- 「ダミー実装／本実装」の状態を **実行ログ上で明確に可視化**する
- ChatGPT 等によるコード生成を前提とした場合でも  
  **仕様逸脱を検知しやすい構造**を提供する

`sansa-testkit` 自体は **業務ロジックを一切持たない**。

---

## 2. 適用範囲

`sansa-testkit` は以下に適用される。

- 共通基盤モジュール
  - `sansa-testkit`
  - `sansa-logging`（※段階的に testkit 方式へ移行）
- 各業務モジュール
  - `sansa-auth`
  - 将来追加される API / Web / XR / 管理系モジュール

---

## 3. 提供機能（初期版）

### 3.1 TestPrinter

- テスト番号付きでテスト結果を標準出力に出力
- 成功 / 失敗 / サマリを人間可読な形式で表示
- JUnit の成否判定とは独立した「表示専用レイヤ」

### 3.2 テスト番号体系の統一

- 共通基盤・業務モジュールで **一貫した命名規約**を使用
- テスト仕様書・テストマトリクス・テストコード・CIログを結合

### 3.3 ダミー実装マーカー

- `@DummyImplementation` により、暫定実装を明示
- 出力ログに `[DUMMY]` を付与

---

## 4. 基本方針（重要）

- **テストコードのみを正としない**
- 必ず以下の 2 点以上で内容が確認できる状態を維持する
  - テスト仕様ドキュメント
  - テストコード
  - 実行ログ（TestPrinter 出力）
