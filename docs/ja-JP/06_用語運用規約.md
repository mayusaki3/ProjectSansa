# 用語運用規約

## 1. 概要

本規約は、ProjectSansa および Sansa エコシステム全体における用語運用方針を定義します。

本規約では、用語そのものの定義ではなく、用語の管理・命名・共有・意味整合性維持のための運用方針を扱います。

共通用語そのものは、`07_共通用語定義` 配下で管理します。

---

## 2. 目的

本規約は、以下を目的とします。

- リポジトリ間の意味整合性維持
- LLM による意味誤認防止
- ドキュメント間の表現統一
- 多国語対応時の意味固定
- 共通概念の一元管理
- シリーズ間相互運用性維持

---

## 3. 基本方針

### 3-1. 日本語主体

ドキュメント本文は、日本語主体で記述します。

英語を説明文として多用することは避け、日本語読者が自然に理解できる記述を優先します。

---

### 3-2. 英語補記

以下に該当するものは、必要に応じて英語補記を使用します。

- 正式用語
- 規格名
- API 名
- スキーマ名
- 識別子
- リポジトリ名
- 外部仕様との対応維持が必要な用語

初回出現時のみ：

```text
日本語（English term）
```

形式を推奨します。

以後は、日本語表記を優先します。

---

### 3-3. カタカナ語

日本語圏で定着済みの技術用語は、カタカナ語を優先します。

例：

- リポジトリ
- エコシステム
- ランタイム
- ワークフロー
- ガバナンス
- クリエイター

---

## 4. 共通用語管理方針

ProjectSansa は、Sansa エコシステム全体の共通用語管理元として扱います。

各シリーズ・各リポジトリは：

- 共通用語を参照する
- リポジトリ固有拡張のみ追加する

構成を基本とします。

共通概念を各リポジトリで独自定義することは避けます。

---

## 5. 用語分類方針

用語は、以下のように分類します。

| 分類 | 内容 |
|---|---|
| エコシステム概念 | シリーズ全体に関する概念 |
| XR・空間概念 | XR・空間共有に関する概念 |
| リポジトリ連携概念 | リポジトリ連携構成に関する概念 |
| 著作物来歴記録概念 | provenance 関連概念 |
| ガバナンス概念 | governance 関連概念 |
| 知識管理概念 | LLM・知識共有関連概念 |

---

## 6. 用語追加方針

新しい共通概念を追加する場合は、以下を定義することを推奨します。

- 用語名
- 英語名
- 意味
- 使用範囲
- 禁止される誤用
- 関連用語
- 共通概念か固有概念か

共通概念へ追加する場合は、既存概念との意味衝突がないことを確認します。

---

## 7. 用語統一方針

同一概念に対して複数表記を混在させることは避けます。

推奨例：

```text
リポジトリ（repository）
```

初回のみ。

以後：

```text
リポジトリ
```

へ統一します。

---

## 8. 禁止事項

以下を避けます。

- 同一概念への複数表記混在
- リポジトリごとの独自意味変更
- 未定義用語の乱用
- 外部規格用語への独自意味付与
- ローカライズ済みメッセージを意味定義として扱うこと

---

## 9. LLM 利用時の注意

LLM は、同一概念への複数表記混在により、別概念として誤認する場合があります。

そのため、以下を重視します。

- 用語統一
- glossary 管理
- 初回英語補記
- 共通概念の集中管理
- リポジトリ責務分離

特に、同一文脈で：

```text
repository
リポジトリ
```

のような混在を避けます。

本規約は LLM の運用方法そのものを定義するものではない。

LLM の利用手順や作業手順は HLDocS および LLM_Rules を参照する。

---

## 10. 共通用語定義との関係

本規約は、用語運用方針のみを定義します。

共通用語そのものは、`07_共通用語定義` 配下で管理します。
