# sansa-testkit 概要と目的

## 位置づけ

`sansa-testkit` は、Project Sansa の各モジュールで共通して利用するテストユーティリティ群です。  
主な目的は以下のとおりです。

- モジュール横断で**テスト出力フォーマット**を統一する  
- **テスト番号（例: M01:UT-01-001）**と実装・ドキュメント（テストマトリクス）を結びつけやすくする  
- 将来的に、**ダミー実装／本実装の区別**（`@DummyImplementation` など）を出力から判別できるようにする下地を提供する  

## 想定利用モジュール

- `sansa-auth`（認証・セッションモジュール）
- 将来追加される Project Sansa の各バックエンドモジュール（例: グループ管理、プロファイル管理 など）

## 提供機能（初期版）

初期版では、主に以下を提供します。

- テストケースの開始・結果・サマリを標準出力へ整形して出力する `TestPrinter`
- テスト番号（`M01:UT-xx-yyy` / `M01:IT-xx-yyy`）を一貫した形式で扱うための規約
- 将来の拡張に備えた、ダミー実装マーカー用の仕組みの導入余地（`@DummyImplementation` など）

詳細なテスト番号規約と出力フォーマットについては  
「[02_テスト番号と出力フォーマット](02_テスト番号と出力フォーマット.md)」を参照してください。
