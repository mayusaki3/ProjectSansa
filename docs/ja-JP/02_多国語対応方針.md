# 多国語対応方針

ドキュメントやコード内部のコメントなどに使用する言語は日本語を基本とします。  
コード内部で使用するIDなどは、すべて英語表記とします。  
コード内に埋め込むメッセージは英語のみで、外部リソース(例: resource/ja-JP/message.json)で日本語に対応してください。  

```
├───resource
│   └───ja-JP
│       └───message.json
```

- リソースなしまたはen-USリソースがある場合、英語表示
- ja-JPリソースがある場合、日本語表示
- それ以外の言語については、翻訳リソースを用意すれば表示可能にしたい。

---

ドキュメントについては、docs/ja-JP のように、言語ごとに作成できます。  

```
├───docs
│   ├───en-US
│   └───ja-JP
```

その際、HLDocSの規約に従い、doc-id / sec_id は維持したまま翻訳してください。

- [HLDocS (Human–LLM Document Rule Specifications)](https://github.com/mayusaki3/HLDocS)

---

README.md だけは特別で、多言語対応する場合は README_en-US.md のように名前を付けて、リポジトリ直下に翻訳版を作成してください。  
README内部で言葉が入ったイラストなどを参照している場合は、docs/en-US/Illustrations に翻訳したものを格納し、それを参照するようにしてください。

```
README.md
README_en-US.md
```

これらの README の先頭には、言語切り替えのリンクを作成してください。  
README で言語を切り替えて、言語別ドキュメントに接続します。

```markdown
# 各READMEの先頭に、以下様に言語切り替えリンクを置いてください。
[日本語](./README.md) | [English](./README_en-US.md)

# 日本語版 README.md から目次へのリンク例
- [ProjectSansa 目次](./docs/ja-JP/目次.md)

# 英語版 README.md から目次へのリンク例
- [ProjectSansa Table of Contents](./docs/en-US/index.md)
```
