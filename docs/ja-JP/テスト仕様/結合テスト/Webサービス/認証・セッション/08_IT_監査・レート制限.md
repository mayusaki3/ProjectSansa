# 08. 監査ログ / レート制限

## 監査ログ
### M01:IT-08-001: REGISTER 系
- pre-register / verify-email / register の各成功/失敗で監査行が出力
- 必須項目: `type`, `traceId`, `user/email(or null)`, `ip`, `ua`, `result`, `detail`, `at(sessionId?)`

### M01:IT-08-002: LOGIN / LOGOUT / LOGOUT_ALL
- 成功/失敗時の `amr`、`sessionId`、`tv(before/after)` を確認

### M01:IT-08-003: MFA
- enroll/activate/verify、メール送信、Recovery 発行/検証の監査を確認

## レート制限
### M01:IT-08-004: pre-register の 429
- `RateLimM01:IT-Remaining` 減少、枯渇後は 429、`Retry-After` 付与

### M01:IT-08-005: MFA email/send の 429
- 上記と同様

### M01:IT-08-006: パスワードリセットAPIの監査ログ・RateLimit
- When: /auth/password/reset/init を短時間で複数回呼出
- Then: 2回目以降429, Retry-After含む, audit_logに event=reset.init 記録
