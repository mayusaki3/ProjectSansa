# 12. パスワードリセット（init / verify / complete）

### M01:IT-12-001: reset.init 正常
- When: `POST /auth/password/reset/init`  
  - body: `{ email: "registered@example.com" }`
- Then:
  - 200、`ok: true`
  - MailHog に reset.init 通知メールが1通送信
  - メール本文に reset.verify 用コード含む  
    （参照：[11_IT_Mail_メール処理E2E.md]）

---

### M01:IT-12-002: reset.init 未登録メール
- When: `POST /auth/password/reset/init`  
  - body: `{ email: "unknown@example.com" }`
- Then:
  - 200、`ok: false`
  - メールは送信されない  
  - レスポンスには `error: "email_not_found"` を含む

---

### M01:IT-12-003: reset.init RateLimit 超過
- Given: 同一メール宛に短時間で複数リクエスト
- Then:
  - 429、`Retry-After` ヘッダあり
  - audit_log に `event=reset.init` を記録  
    （参照：[08_IT_監査・レート制限.md]）

---

### M01:IT-12-004: reset.verify 正常
- When: `POST /auth/password/reset/verify`  
  - body: `{ email, code }`
- Then:
  - 200、`ok: true`
  - 一時セッション発行 (`resetToken`)
  - コードは1回限り有効

---

### M01:IT-12-005: reset.verify 期限切れ or 無効コード
- Given: 無効/期限切れコード
- Then:
  - 400、`type="https://errors.sansa.dev/reset/invalid_code"`

---

### M01:IT-12-006: reset.complete 正常
- When: `POST /auth/password/reset/complete`  
  - body: `{ email, newPassword, resetToken }`
- Then:
  - 200、`ok: true`
  - 新パスワードでログイン可能
  - 旧トークン無効化（`tv++`）  
  - `/sessions` 呼出時は空配列  
    （参照：[04_IT_セッション列挙・個別失効.md]）

---

### M01:IT-12-007: reset.complete パスワード不一致
- When: `newPassword` と `confirmPassword` が異なる
- Then:
  - 400、`type="https://errors.sansa.dev/password/mismatch"`

---

### M01:IT-12-008: reset.complete 使用済み resetToken
- Given: 同一トークンを再使用
- Then:
  - 401、`type="https://errors.sansa.dev/reset/reused"`

---

### M01:IT-12-009: reset.complete 完了通知メール
- When: 完了処理後
- Then:
  - MailHog に reset.complete 通知メールが1通送信  
    （参照：[11_IT_Mail_メール処理E2E.md]）
  - 件名 `"パスワードが再設定されました"`

---

### M01:IT-12-010: reset.complete 後の再ログイン
- Given: パスワード変更完了 (`tv++`)
- When: 旧RefreshTokenで `/auth/token/refresh`
- Then:
  - 401、`type="https://errors.sansa.dev/token/reused"`
  - 新ログイン要求が必要  
    （参照：[03_IT_ログイン・MFA誘導・現在セッション.md], [06_IT_トークン_TTL・リフレッシュ・改竄・tv.md]）
