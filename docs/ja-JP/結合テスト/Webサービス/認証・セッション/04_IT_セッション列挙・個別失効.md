# 04. セッション列挙 / 個別失効（/sessions）

### M01:IT-04-001: GET /sessions（複数端末）
- Given: 2つ以上のログインセッションを作成
- When: `GET /sessions`
- Then: 200、`sessions.length>=2`

### M01:IT-04-002: DELETE /sessions/{id}（存在する）
- Then: 204（対象セッションの以後アクセスは 401/無効）

### M01:IT-04-003: DELETE /sessions/{id}（存在しない）
- Then: 404、`type=*session_not_found`

### M01:IT-04-004: パスワードリセット直後のセッション列挙
- Given: tv更新直後
- When: /sessions 呼び出し
- Then: 空配列（全端末無効化後）
- Notes: logout_all相当の効果確認
