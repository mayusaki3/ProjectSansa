# 開発時専守事項

## 1. 目的

本書は、README.md に含まれていた開発時専守事項を `docs/ja-JP` 配下へ分離したものである。

## 2. 多言語化対応

基本的に使用言語は日本語とする。ただし、コード内部で使用する ID、スキーマキー、API フィールド、エラーコード、イベント ID などは英語基準とする。

コード内に埋め込むメッセージは英語を基準とし、日本語やその他言語の表示は外部リソースで対応する。

## 3. LLM 利用方針

Sansa 系列では、LLM を利用した開発を想定する。ただし、LLM の作業対象は原則としてリポジトリ単位で分離する。

## 4. ドキュメント管理

ドキュメント管理は HLDocS 準拠を基本とする。

## 5. LLM_Workspace

各リポジトリには、必要に応じて次のフォルダを作成できる。

```text
LLM_Workspace
```

## 6. 申し送り

Sansa 系列リポジトリ間で仕様のすり合わせが必要な場合は、申し送り情報を作成する。

```text
LLM_Workspace/Handover/*
LLM_Workspace/Request/*
```

## 7. 共通情報の扱い

用語定義など、全 Sansa リポジトリに関係する情報は ProjectSansa で管理する。各リポジトリ固有の開発手順、CI/CD、実装ルール、詳細設計は各リポジトリ側で管理する。
