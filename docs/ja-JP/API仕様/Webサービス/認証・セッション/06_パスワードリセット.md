# パスワードリセット

## 概要
利用者がパスワードを忘れた場合の本人確認および再設定フローを提供する。

## エンドポイント

| # | 概要 | Method / Path |
|---|---|---|
| 1 | リセット要求（メール送信） | `POST /auth/password/reset/request` |
| 2 | トークン検証 | `POST /auth/password/reset/verify` |
| 3 | パスワード再設定 | `POST /auth/password/reset/confirm` |
| 4 | リセットメール再送（任意） | `POST /auth/password/reset/resend` |

## DTO（ドキュメント定義）

### A) `POST /auth/password/reset/request`
**Request**
| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| email | string | ✅ | 登録メールアドレス |
| locale | string | 任意 | メールテンプレート言語 |

**Response**
| フィールド | 型 |
|---|---|
| ok | boolean |

- アカウント有無を秘匿し常に 200。
- サーバ側で短期有効の使い捨てトークンを生成し、メール送信。

---

### B) `POST /auth/password/reset/verify`
**Request**
| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| token | string | ✅ | メール記載のトークン |

**Response**
| フィールド | 型 | 説明 |
|---|---|---|
| ok | boolean | 成功時 true |
| methods | object | MFA 要求情報 |
| methods.mfaRequired | boolean | MFA が必要か |
| methods.allowed | string[] | `['email','totp','recovery']` 等 |

---

### C) `POST /auth/password/reset/confirm`
**Request**
| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| token | string | ✅ | 検証済みトークン |
| newPassword | string | ✅ | 新しいパスワード |
| mfa | object | 任意 | MFA 検証情報（type, code） |

**Response**
| フィールド | 型 |
|---|---|
| ok | boolean |

- 成功時は全セッションを失効（05_セッション管理.md 参照）。

---

### D) `POST /auth/password/reset/resend`
**Request**
| フィールド | 型 | 必須 |
|---|---|---|
| token | string | ✅ |

**Response**
| フィールド | 型 |
|---|---|
| ok | boolean |

---

## バリデーション / レート
- リクエスト/再送はアカウント・メール・IP単位でレート制限。  
- トークンは 1 回限り・短期有効（15分程度）・署名付き。  
- トークンは送信先メールにバインドし他者利用不可。

## セキュリティ / 監査
- 監査イベント: `PASSWORD_RESET_REQUESTED`, `PASSWORD_RESET_VERIFIED`, `PASSWORD_RESET_CONFIRMED`  
- パスワード更新時はセッション全失効（`SESSION_INVALIDATE_ALL`）。  
- メールテンプレートは多言語対応（`locale`）、有効期限明示、フィッシング防止文言を含む。

## ステータスコード
- 200: 成功（存在秘匿）
- 400: 無効トークン・期限切れ
- 401: 認証エラー
- 429: レート制限
- 5xx: サーバエラー
