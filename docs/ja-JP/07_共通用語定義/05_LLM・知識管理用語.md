# LLM・知識管理用語

## term-6001 Gateway

LLM が作業開始時に参照する入口。

ProjectSansa では LLM_Rules が Gateway に該当する。

---

## term-6002 LLM_Workspace

LLM が利用する作業領域。

申し送り・依頼・作業ログなどを管理する。

---

## term-6003 Worklog

LLM の作業記録。

正式仕様ではなく、作業補助情報として扱う。

---

## term-6004 Handover

リポジトリ間またはチャット間で共有する申し送り情報。

---

## term-6005 Request

LLM への作業依頼や入力情報。

---

## term-6006 正式知識

docs 配下に格納された安定情報。

ProjectSansa における正本。

---

## term-6007 暫定知識

検証中または実験中の情報。

LLM_Rules または LLM_Workspace で管理する。

---
