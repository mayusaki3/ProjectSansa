# リポジトリ構成・ランタイム用語

## term-2001 共通管理リポジトリ

Sansa エコシステム全体の：

- 共通概念
- 用語
- 方針
- リポジトリ間構成

などを管理するリポジトリ。

ProjectSansa が該当します。

---

## term-2002 リポジトリ固有概念

特定リポジトリのみで使用される概念。

例：

- 特定ゲームエンジン専用実装
- レンダラー固有概念
- シェーダー固有概念

---

## term-2003 ランタイム

実際に動作するシステム本体。

例：

- XR ランタイム
- networking runtime
- multiplayer runtime
