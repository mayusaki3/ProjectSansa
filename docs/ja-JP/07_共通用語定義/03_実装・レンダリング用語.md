# 実装・レンダリング用語

## term-3001 ランタイム実装

ランタイムを構成する実装。

例：

* 描画更新
* 同期処理
* 通信処理
* 物理更新

---

## term-3002 描画実装

GPU / シェーダー / レンダラーを利用する描画処理実装。

例：

* HLSL
* GLSL
* rendering pipeline
* material system

---

## term-3003 特定ゲームエンジン専用実装

特定ゲームエンジン専用の実装。

例：

* Unity 専用実装
* Unreal Engine 専用実装
* O3DE 専用実装

---

## term-3004 特定ゲーム専用実装

特定ゲーム専用のロジックやデータ。

例：

* combat system
* inventory
* quest
* NPC AI
