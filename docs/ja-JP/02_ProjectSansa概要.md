# ProjectSansa概要

## 1. 位置づけ

ProjectSansa は、Sansa 系列の個別実装リポジトリを束ねるための構想・共通認識・導線を管理するリポジトリである。

ProjectSansa 自体は、特定の Runtime、フォーマット実装、Web サービス、AI ツール、レンダリング処理を直接実装するためのリポジトリではない。

## 2. 目的

ProjectSansa は、現実世界・仮想世界・理想が交差する xR システム構想として、VR / AR / MR / 非XR を横断する体験の共通土台を整理する。

## 3. ProjectSansa に残す情報

| 種類 | 扱い |
|---|---|
| 全体構想 | ProjectSansa に残す |
| 世界観・目的 | ProjectSansa に残す |
| Sansa 系列リポジトリの関係 | ProjectSansa に残す |
| 共通用語 | ProjectSansa に残す |
| 共通運営方針 | ProjectSansa に軽量に残す |
| 個別実装 | 各リポジトリへ移す |
| 詳細な開発手順 | 各リポジトリへ移す |
